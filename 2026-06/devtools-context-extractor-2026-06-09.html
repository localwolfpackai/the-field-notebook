The console is a context machine — nine snippets that feed an AI clean pages.

I spent a week pasting raw page HTML into a model and watching it guess in circles. Then I moved the cleanup upstream — into the Chrome DevTools console — and the model stopped guessing. These are the paste-once snippets that turn any live website into a tidy, low-token payload your agent can actually rebuild from.

—Lupo · The Mess is the Method
Read · ~13 min Surface · Chrome DevTools console + $0 Assumes · you've opened DevTools once Voice · open-notebook, casual

Here's the thing nobody tells you when you start handing live websites to an AI: the model isn't bad at frontend — it's drowning. Copy a real page's outerHTML and you've just shoved fifty thousand tokens of hidden SVGs, base64 images, tracking scripts and twelve-deep <div> soup into a context window that wanted maybe three thousand. The signal is in there. It's just buried.

The fix I kept reaching for wasn't a better prompt. It was doing the cleanup before the model ever sees the page — right in the browser console, where I already have the live DOM in my hands. Each of these snippets clones the page, strips the noise, and drops a clean Markdown payload straight onto my clipboard. Run it, paste it, ship the prompt.

Below: nine snippets I actually keep saved, grouped into the three jobs I use them for — clone a component, debug a layout, and extract the whole page. Each gets the code, the one-line claim, and the prompt I paste alongside it. Steal the ones that fit how you build.

First, the thing that was actually breaking. why

I have a real transcript of this going wrong. I selected a card on a Tailwind site and asked an AI assistant to tell me how it laid out at different breakpoints. It came back with confident, detailed answers — and they were wrong. It kept reporting display: block on an element the screenshot clearly showed as a flex row, then apologizing, then guessing again. Four rounds of "my previous inspection was inaccurate."

The model wasn't dumb. It was working from a selector string like a.relative.inline-flex.items-center.rounded-full.py-1\.5... — forty escaped Tailwind classes deep — with none of the computed values it needed and a wall of sibling nodes it didn't. Garbage context in, confident garbage out. That's the Token Trap, and it's the whole reason this notebook exists.

01

The whole trick is one function: copy(). setup

Before any snippet, the one thing to internalize. DevTools gives you a global copy() in the console that puts any string straight on your clipboard. Every snippet below ends with it. You run the snippet, and the finished, formatted payload is already copied — no selecting, no right-click. Tab over to your AI, paste, done.

Two more console primitives you'll see throughout: $0 is whatever element you last clicked in the Elements panel (DevTools assigns it for you), and document is the live page. That's the entire vocabulary.

console — the 10-second version 
// $0 = the element you clicked in Elements. try it:
> copy($0.outerHTML)
undefined   // ← but your clipboard now holds the HTML

// the snippets just do this, minus the garbage. e.g.
> copy("### anything\n" + cleanedMarkdown)
save it ↳

02

!ai-theme — rip a site's colors and fonts in one run. clone

Run this without selecting anything. It walks every element on the page, collects the rendered colors and the font stacks actually in use, dedupes them, and copies a clean token list. This is the constraint sheet you hand a model so its new component matches the site instead of inventing its own palette.

snippet · !ai-theme 
(function designSystemExtractor() {
  const colors = new Set(), fonts = new Set();
  document.querySelectorAll('body *').forEach(el => {
    const s = window.getComputedStyle(el);
    if (s.color !== 'rgba(0, 0, 0, 0)') colors.add(s.color);
    if (s.backgroundColor !== 'rgba(0, 0, 0, 0)') colors.add(s.backgroundColor);
    if (s.fontFamily) fonts.add(s.fontFamily.split(',')[0].replace(/"/g, ''));
  });
  copy(`### Design System\nColors:\n` + [...colors]
    .filter(c => c !== 'transparent').join('\n')
    + `\nFonts:\n` + [...fonts].join('\n'));
})();

Pair it with the next snippet and you've handed the model both halves of the job: here are the site's rules, and here's the thing to rebuild inside them.

03

!ai-component — clone one element, minus the noise. clone

This is the one that fixed my apology loop from #0. Click the element in the Elements panel (so it becomes $0), run the snippet. It grabs the handful of computed styles that actually drive layout, clones the markup, and strips every attribute except the four that matter — class, id, src, href. No data-*, no framework gunk, no escaped-selector hell. Clean HTML plus the exact computed values, formatted as Markdown.

snippet · !ai-component 
(function aiComponentHarvester(el = $0) {
  if (!el) return console.warn("Select element first.");
  const s = window.getComputedStyle(el);
  const keys = ['display','flex-direction','justify-content',
    'align-items','gap','padding','margin','background-color',
    'color','font-size','font-weight','border-radius'];
  const css = keys.map(k => `${k}: ${s.getPropertyValue(k)};`)
    .filter(v => !v.includes('normal') && !v.includes('none')
      && !v.includes('0px')).join('\n');
  const clone = el.cloneNode(true);
  clone.querySelectorAll('*').forEach(n => Array.from(n.attributes)
    .forEach(a => { if (!['class','id','src','href'].includes(a.name))
      n.removeAttribute(a.name); }));
  copy(`### Cleaned HTML:\n\`\`\`html\n` + clone.outerHTML
    + `\n\`\`\`\n### Computed Styles:\n\`\`\`css\n` + css + `\n\`\`\``);
})();

04

!toggle-wireframe — strip the page to bones, then screenshot it. debug

When a layout breaks, a screenshot of the styled page hides the problem — the gradients and shadows distract you and the model both. This toggle injects a stylesheet that flattens everything to thin outlines, dims the media, and kills shadows. Suddenly every box, gap, and overflow is visible. Run it again to remove it. Take a DevTools node screenshot in this state and the model can see the structure.

snippet · !toggle-wireframe 
(function toggleWireframe() {
  const id = 'ai-wireframe';
  let el = document.getElementById(id);
  if (el) el.remove();          // already on → toggle off
  else {
    el = document.createElement('style'); el.id = id;
    el.innerHTML = `* { background: transparent !important;
      color: #444 !important;
      border: 1px solid rgba(0,0,0,0.15) !important;
      box-shadow: none !important; text-shadow: none !important; }
      img, svg, video, iframe {
      opacity: 0.3 !important; border: 1px dashed red !important; }`;
    document.head.appendChild(el);
  }
})();
try it ↳
Open any cluttered marketing site, run this, and watch it become a blueprint. The first time an overflowing div just appears as a box poking past its parent, you'll get why this beats squinting at the styled version.
05

!ai-skeleton — the component as a labeled list. debug

Screenshots are great, but the model also wants the structure as text it can reason over. With your container selected, this walks its tree and emits a tidy list of the elements that carry meaning — images with their alt text, buttons and links with their labels and targets, headings with their text. No styling, no wrappers. Just what this thing is made of.

snippet · !ai-skeleton 
(function mapComponent(el = $0) {
  if (!el) return console.warn("Select element first.");
  let out = `### Component Skeleton\n`;
  const w = document.createTreeWalker(el, NodeFilter.SHOW_ELEMENT);
  let n;
  while (n = w.nextNode()) {
    const t = n.tagName.toLowerCase(),
      txt = n.innerText ? n.innerText.trim().replace(/\n/g, ' ') : '';
    if (t === 'img')
      out += `- 🖼️ [IMG] Src: ${n.src.split('/').pop()} | Alt: "${n.alt}"\n`;
    else if (t === 'button' || t === 'a')
      out += `- 🖱️ [${t.toUpperCase()}] "${txt}" | Href: ${n.href || 'N/A'}\n`;
    else if (/^h[1-6]$/.test(t))
      out += `- 📌 [${t.toUpperCase()}] "${txt}"\n`;
  }
  copy(out);
})();
debug Here's a wireframe screenshot and the component's semantic structure. The button overflows its container on mobile. Find the exact DOM node and CSS property causing the break, and give me the specific fix.

Wireframe screenshot for the eyes, skeleton list for the reasoning. Two cheap snippets, and the model is debugging your actual layout instead of a hallucinated one.

06

!ai-clipper — pure content, zero chrome. extract

Not every job is about layout. Sometimes you just want the words — to rewrite, summarize, or re-target for SEO. Highlighting a whole page and pasting it drags in nav, footer, cookie banners and sidebar junk that waste tokens and confuse the model about what's actually the article. This targets <article> or <main>, violently removes the noise, and copies clean prose.

snippet · !ai-clipper 
(function webClipper() {
  const main = document.querySelector('article')
    || document.querySelector('main') || document.body;
  const clone = main.cloneNode(true);
  clone.querySelectorAll('nav, footer, header, aside, script, style, svg, iframe, [class*="ad-"]')
    .forEach(el => el.remove());
  copy(`### Web Content\n`
    + clone.innerText.replace(/\n{3,}/g, '\n\n').trim());
})();

!ai-page-map — the whole page as a topography tree. macro

When the question is structural — "why is my sticky sidebar scrolling away?" — the model doesn't need text or color, it needs the shape of the page. This ignores everything but the semantic and container-level nodes and builds an indented Markdown tree of the macro layout: headers, mains, sections, navs, the big wrappers. Depth-capped so it never runs away on an absurdly nested site.

snippet · !ai-page-map 
(function mapPageTopography() {
  function getStructure(node, depth = 0) {
    if (depth > 6) return '';   // safety: don't dig forever
    let out = '';
    Array.from(node.children).forEach(child => {
      const tag = child.tagName.toLowerCase();
      const id = child.id ? `#${child.id}` : '';
      const structural = ['header','main','footer','section',
        'article','nav','aside','form','ul','dialog'].includes(tag);
      const bigDiv = tag === 'div' && (child.id
        || child.className.includes('container')
        || child.className.includes('wrapper'));
      if (structural || bigDiv) {
        out += `${'  '.repeat(depth)}- <${tag}${id}>\n`;
        out += getStructure(child, depth + 1);
      } else if (child.children.length) out += getStructure(child, depth);
    });
    return out;
  }
  copy(`### Page Topography Map\n` + getStructure(document.body));
})();

paste it and ask: "which container is breaking my sticky context?" — it'll point at the node.

!ai-dom-lite — the entire page, 50k tokens down to 3k. macro

This is the headline snippet — the one that names the whole notebook. When you genuinely need the full page structure (rebuilding a landing page, say), this clones the body, deletes every heavy non-structural tag (script, svg, iframe, canvas, video…), strips all but a handful of attributes, and truncates long text runs so paragraphs don't eat your context. What's left is pure layout: classes and structural nodes, nothing else.

snippet · !ai-dom-lite 
(function exportCleanDOM() {
  const clone = document.body.cloneNode(true);
  // 1. nuke the heavy, non-structural elements
  clone.querySelectorAll('script, style, svg, path, iframe, noscript, canvas, video')
    .forEach(el => el.remove());
  // 2. strip noisy attrs + truncate long text
  const walker = document.createTreeWalker(clone, NodeFilter.SHOW_ELEMENT);
  let node;
  while (node = walker.nextNode()) {
    Array.from(node.attributes).forEach(attr => {
      if (!['id','class','href','src','alt','type','name']
        .includes(attr.name)) node.removeAttribute(attr.name);
    });
    Array.from(node.childNodes).forEach(child => {
      if (child.nodeType === Node.TEXT_NODE) {
        const text = child.nodeValue.trim();
        if (text.length > 80)
          child.nodeValue = text.substring(0, 80) + '... [text truncated]';
      }
    });
  }
  copy(`### Token-Optimized DOM\n\`\`\`html\n` + clone.innerHTML + `\n\`\`\``);
})();
the combo ↳
For a full live-site audit: run !ai-theme for the brand colors, then !ai-dom-lite for the structure, paste both, and say "rebuild this page in React + Tailwind using these exact tokens." That's two snippets standing in for a thousand-line copy-paste.

!scrape-api — bake the prompt into the payload. extract

The upgrade that made all of these stick: stop typing the instruction every time. You can append the system prompt inside the snippet, so the clipboard already holds "act as X, do Y" plus the data. Run, paste, hit enter — the model knows the job before you say a word. This one is the sharpest example: turn the net on, click around the app, and it catches the first real JSON response, then copies it with a request to reverse-engineer the TypeScript types.

snippet · !scrape-api (toggle on, then click around) 
(function interceptAPIWithPrompt() {
  if (window._apiScraperActive) {
    window._apiScraperActive = false;
    return console.log("🛑 API Net OFF.");
  }
  window._apiScraperActive = true;
  console.log("🎣 API Net ON. Click around — next JSON payload gets caught.");

  const originalFetch = window.fetch;
  window.fetch = async function(...args) {
    const response = await originalFetch.apply(this, args);
    response.clone().json().then(data => {
      const url = typeof args[0] === 'string' ? args[0] : args[0]?.url;
      if (!url.includes('analytics') && !url.includes('telemetry')) {
        window._apiScraperActive = false;  // catch one, then stop
        const aiPrompt = `Act as a backend architect. I intercepted a live `
          + `API response from ${url.split('?')[0]}.\n`
          + `Reverse-engineer the likely DB schema and write the exact `
          + `TypeScript interfaces to consume this payload.\n\n`
          + `### Payload:\n\`\`\`json\n`;
        copy(aiPrompt + JSON.stringify(data, null, 2) + `\n\`\`\``);
        console.log("📋 Payload + prompt copied. Net off.");
      }
    }).catch(() => {});
    return response;
  };
})();
heads up ↳
This one monkey-patches window.fetch for the session — reload the tab when you're done to restore the native API. Only run snippets you've read (these are all here in full for exactly that reason), and keep this kind of interception to your own apps and pages you're authorized to inspect. The console is powerful; aim it at your own work.

That's the whole arc of this notebook in one snippet: the browser already holds the live context, the console can serialize it clean, and the prompt can ride along in the payload. You stop being the copy-paste middleman and start programming your agent from the page you're standing on.
